2DFXLAB v1.0.0
===============

Lightweight 2D game particle-effect lab from ARTfunny.

How to run (Windows)
--------------------
1. Unzip this folder anywhere.
2. Double-click START.bat
   — or double-click index.html (Chrome / Edge / Brave).
3. Leave the START.bat window open while you work; close it when you are done.

How to run (Mac)
----------------
1. Unzip this folder.
2. Double-click START.command (right-click → Open the first time if macOS blocks it)
   — or double-click index.html.

The library lives on this device only (browser storage). Clearing site data
removes your effects.

Export (paid build)
-------------------
Use Export in the top bar to download a zip of transparent frames, a contact
sheet, effect.json, textures, and a small canvas player for the open effect.
Export library (bottom left) saves every effect as one JSON backup file.
Import library restores that JSON.

Demo / free-try build
---------------------
Creating effects, presets, Import library, and Restore templates still work.
Effect Export and Export library are locked — use Buy to export (itch.io) for
the full offline export build.

------------
Modern Chromium browser (Chrome, Edge, or Brave). No install needed beyond
unzipping. Offline after unzip — no network required to use the lab.
